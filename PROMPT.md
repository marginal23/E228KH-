# Роль

Ты работаешь как ИИ-агент внутри учебного проекта. Собери цельную одностраничную рекламную веб-страницу из материалов, которые подготовил студент. Сохраняй авторские решения проекта и не подменяй их универсальным современным шаблоном.

# Перед сборкой

1. Прочитай README.md.
2. Полностью прочитай research.md, era.md, concept.md и sources.md.
3. Найди все Markdown-файлы в blocks/ и прочитай их по порядку числовых префиксов.
4. Просмотри доступные файлы в assets/.
5. Кратко сформулируй, какой объект и эпоху представляет проект, кому адресованы курсы, что они обещают, какие блоки входят в страницу и какие визуальные правила нужно соблюдать.
6. Только после этого собирай index.html.

# Источники истины

- research.md — исторические факты и ценность Smalltalk;
- era.md — период, технологическая и визуальная среда;
- concept.md — аудитория, обещание, голос и центральная шутка;
- blocks/*.md — набор, порядок и назначение секций;
- sources.md — подтверждения фактов и визуальные ориентиры;
- assets/ — локальные материалы.

Не меняй Markdown-файлы без отдельной команды студента.

# Главная задача

Создай готовый index.html. Страница рекламирует вымышленные курсы Smalltalk так, как это могло бы выглядеть в выбранной эпохе 1972–1983 годов.

# Содержание

Используй blocks/*.md как структуру страницы и сохраняй порядок файлов.

Не добавляй новые смысловые секции только ради привычной структуры сайта.

Можно улучшать формулировки ради ритма и цельности, но нельзя менять проверенные исторические факты.

Не придумывай даты, цитаты, рейтинги, известных пользователей, события или исторические организации.

Вымышленная учебная лаборатория, цена, расписание и рекламные детали должны быть явно представлены как художественная концепция, а не исторические факты.

# Визуальная система

Опирайся на era.md и sources.md.

Страница должна напоминать исследовательскую компьютерную демонстрацию начала 1980-х: монохромная палитра, прямоугольные окна, тонкие рамки, плотная информация, технические подписи, экранные элементы и схемы.

Не используй современные огромные скруглённые карточки, стеклянный дизайн, градиентные пятна, неон, современные UI-библиотеки или внешние CDN.

# Технический результат

- основной файл — index.html;
- открытие двойным щелчком без сервера;
- CSS внутри HTML;
- JavaScript только при необходимости;
- никаких внешних зависимостей;
- все локальные материалы подключать относительными путями;
- обычный экран ноутбука должен отображать страницу без перекрытия текста.

# Самопроверка

Сопоставь index.html с research.md, era.md, concept.md и каждым blocks/*.md.

Проверь:
- понятна историческая ценность Smalltalk;
- эпоха узнаётся по нескольким согласованным признакам;
- все блоки присутствуют;
- нет выдуманных исторических утверждений;
- вымышленная реклама отделена от истории;
- страница открывается локально;
- визуальная система едина.

Исправь технические ошибки, но сохраняй решения студента.
